# Bioinfo-Scripts

A collection of foundational bioinformatics scripts written in Python and R.  
---

## Purpose

This repository is part of my academic portfolio as a postgraduate bioinformatics student. It documents my journey in mastering core scripting techniques and data operations essential for research in:

- Next-Generation Sequencing (NGS)
- Genome analysis
- Sequence annotation
- Basic statistical programming
- Pathogen informatics and epidemiology
